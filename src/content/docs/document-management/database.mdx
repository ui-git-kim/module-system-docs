Document Management ships a **self-contained** Prisma schema: eight tables, all prefixed with `doc_` — `doc_storage_provider`, `doc_document`, `doc_node_link`, `doc_folder_bookmark`, `doc_recent_access`, `doc_app_settings`, `doc_included_folder`, and `doc_parsed_artefact`. The schema adds **no `@relation` directives** and never modifies the `User` model or the Structure module's tables. Foreign keys to other modules (the owning user, a Structure node) are stored as plain `String` fields with `@@index` for fast lookups.

<Aside type="note" title="Connector, not storage">
These tables hold **references, metadata, and your organisation** of files (favourites, tags, node links, audit trail). They never store file content — the bytes stay in the external storage provider. `doc_document` is a pointer to a file that lives in S3, WebDAV, or a local folder.
</Aside>

The scaffold appends these models to your app's Prisma schema at `init` and **applies the schema migrate for you** — no manual migrate step is needed. As of module-starter scaffold **v1.31.9** it does this the drift-immune way (an offline `prisma migrate diff` → a real migration file → `prisma migrate deploy`, so a shared DB with runtime-created objects is never reset); older scaffolds ran `prisma migrate dev` at `init`. Avoid running `prisma migrate dev` by hand on an app that carries runtime-created DB objects — use `prisma migrate deploy` if you ever need to apply migrations manually.

## `doc_storage_provider`

A configured connection to an external storage service. The `config` column holds **AES-256-GCM encrypted JSON** (credentials) — never plaintext. See [Security](/document-management/security/) for the encryption model.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `String` | `@id @default(cuid())` |
| `userId` | `String` | Owner |
| `name` | `String` | e.g. `"My NAS"`, `"Company R2 Bucket"` |
| `providerType` | `String` | `s3` \| `r2` \| `webdav` \| `local` |
| `config` | `String` `@db.Text` | Encrypted JSON connection details |
| `isDefault` | `Boolean` | `@default(false)` |
| `isReadOnly` | `Boolean` | `@default(false)` — blocks upload/modify/delete via the module |
| `isEphemeral` | `Boolean` | `@default(false)` — Local Connect: raw reachable only while the user's machine is connected. Derived artefacts are never stored here; raw bytes are never persisted server-side |
| `status` | `String` | `@default("pending")` — `connected` \| `error` \| `pending` \| `unavailable` |
| `statusMessage` | `String?` | Human-readable status detail |
| `lastCheckedAt` | `DateTime?` | Last connection test |
| `basePath` | `String?` | Optional root path within the provider |
| `uploadPath` | `String?` | Default folder for app uploads (relative to the provider) |
| `metadata` | `Json?` | Provider settings/capabilities cache |
| `createdAt` | `DateTime` | `@default(now())` |
| `updatedAt` | `DateTime` | `@updatedAt` |

```prisma
model doc_storage_provider {
  id            String    @id @default(cuid())
  userId        String
  name          String
  providerType  String
  config        String    @db.Text
  isDefault     Boolean   @default(false)
  isReadOnly    Boolean   @default(false)
  isEphemeral   Boolean   @default(false)
  status        String    @default("pending")
  statusMessage String?
  lastCheckedAt DateTime?
  basePath      String?
  uploadPath    String?
  metadata      Json?
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt

  @@index([userId])
  @@map("doc_storage_providers")
}
```

## `doc_document`

A lightweight reference to a file in connected storage. A row is created when you interact meaningfully with a file (favourite, tag, note, link to a node) **or** when another module requests a stable reference via the service registry (for example cog-ingest needing a durable `documentId` to cite). Not every browsed file gets a row.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `String` | `@id @default(cuid())` |
| `userId` | `String` | Owner |
| `providerId` | `String` | References `doc_storage_provider.id` |
| `remotePath` | `String` | Full path within the provider |
| `fileName` | `String` | |
| `mimeType` | `String?` | |
| `fileSize` | `Int?` | Bytes |
| `contentHash` | `String?` | SHA-256 of the file at reference time (integrity) |
| `isFavourite` | `Boolean` | `@default(false)` |
| `status` | `String` | `@default("active")` — `active` \| `archived` |
| `tags` | `String[]` | `@default([])` |
| `notes` | `String?` `@db.Text` | User notes |
| `thumbnailPath` | `String?` | Cached thumbnail path/URL |
| `metadata` | `Json?` | Provider metadata cache |
| `lastAccessedAt` | `DateTime?` | |
| `lastSyncedAt` | `DateTime?` | Last metadata refresh from the provider |
| `createdAt` | `DateTime` | `@default(now())` |
| `updatedAt` | `DateTime` | `@updatedAt` |

```prisma
model doc_document {
  id             String    @id @default(cuid())
  userId         String
  providerId     String
  remotePath     String
  fileName       String
  mimeType       String?
  fileSize       Int?
  contentHash    String?
  isFavourite    Boolean   @default(false)
  status         String    @default("active")
  tags           String[]  @default([])
  notes          String?   @db.Text
  thumbnailPath  String?
  metadata       Json?
  lastAccessedAt DateTime?
  lastSyncedAt   DateTime?
  createdAt      DateTime  @default(now())
  updatedAt      DateTime  @updatedAt

  @@unique([userId, providerId, remotePath])
  @@index([userId, createdAt])
  @@index([userId, isFavourite])
  @@index([userId, status])
  @@map("doc_documents")
}
```

The `@@unique([userId, providerId, remotePath])` constraint backs the `upsert` used when you favourite or link a file, so re-referencing the same file updates the existing row rather than duplicating it.

## `doc_node_link`

A junction table linking documents to Structure nodes. A document can be linked to multiple nodes. `nodeId` is a plain string (a Structure node id) — there is no `@relation` to the Structure module.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `String` | `@id @default(cuid())` |
| `documentId` | `String` | References `doc_document.id` |
| `nodeId` | `String` | References a Structure node |
| `userId` | `String` | Owner |
| `linkType` | `String` | `@default("attachment")` — `attachment` \| `reference` \| `primary` |
| `order` | `Int` | `@default(0)` |
| `notes` | `String?` | |
| `createdAt` | `DateTime` | `@default(now())` |

```prisma
model doc_node_link {
  id         String   @id @default(cuid())
  documentId String
  nodeId     String
  userId     String
  linkType   String   @default("attachment")
  order      Int      @default(0)
  notes      String?
  createdAt  DateTime @default(now())

  @@unique([documentId, nodeId])
  @@index([nodeId])
  @@index([documentId])
  @@index([userId])
  @@map("doc_node_links")
}
```

## `doc_recent_access`

Tracks file access for the "Recent" view, and doubles as a **chain-of-custody audit trail** for legal/evidence use cases (who accessed or downloaded what, and when). The service caps this table at 100 rows per user, pruning the oldest.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `String` | `@id @default(cuid())` |
| `userId` | `String` | Owner |
| `providerId` | `String` | |
| `remotePath` | `String` | |
| `fileName` | `String` | |
| `mimeType` | `String?` | |
| `action` | `String` | `@default("view")` — `view` \| `download` \| `upload` \| `link` \| `unlink` |
| `accessedAt` | `DateTime` | `@default(now())` |

```prisma
model doc_recent_access {
  id         String   @id @default(cuid())
  userId     String
  providerId String
  remotePath String
  fileName   String
  mimeType   String?
  action     String   @default("view")
  accessedAt DateTime @default(now())

  @@index([userId, accessedAt])
  @@index([providerId, remotePath])
  @@map("doc_recent_access")
}
```

## `doc_app_settings`

An app-wide **singleton** (always `id = "app"`) holding the admin **engine policy** — which adapter engines users may configure on their Document Storage settings page. It is **not** user-scoped. An empty `allowedAdapters` means "all installed engines are allowed".

| Field | Type | Notes |
|-------|------|-------|
| `id` | `String` | `@id @default("app")` — single row |
| `allowedAdapters` | `String[]` | Allowed engine ids (`s3` \| `webdav` \| `local`); empty = all installed |
| `defaultProviderId` | `String?` | App-wide shared default provider for users with no default of their own; `null` if unset |
| `defaultIsolateUsers` | `Boolean` | `@default(true)` — namespace each user's uploads under `u/<userId>/` on the shared default and confine access |
| `artefactKeepVersions` | `Int?` | Retention: keep at most the N newest parsed-artefact versions per source + format; `null` = keep every version |
| `artefactMaxAgeDays` | `Int?` | Retention: delete parsed artefacts older than N days on prune; `null` = no age limit |
| `updatedAt` | `DateTime` | `@updatedAt` |

```prisma
model doc_app_settings {
  id                   String   @id @default("app")
  allowedAdapters      String[] @default([])
  defaultProviderId    String?
  defaultIsolateUsers  Boolean  @default(true)
  artefactKeepVersions Int?
  artefactMaxAgeDays   Int?
  updatedAt            DateTime @updatedAt

  @@map("doc_app_settings")
}
```

The engine policy is read via `GET /settings` (any authenticated user) and written via `PUT /settings` (admin-only). It can only narrow the engines installed at init, never widen them. See [Configuration](/document-management/configuration/) for the user-settings vs admin-policy split.

`artefactKeepVersions` and `artefactMaxAgeDays` hold the admin **parsed-artefact retention** policy — both `null` by default, so **every artefact version is kept forever** (the knowledge base has no automatic decay; cleanup is an explicit admin choice). `keepVersions` is enforced on each `putParsedArtefact` write; `maxAgeDays` (and `keepVersions`) are applied when an admin runs `POST /artefacts/prune`. Both are set through the same admin-only `PUT /settings` and surfaced on the **Parsed-artefact retention** card at `/admin/documents`.

## `doc_included_folder`

Folders a user has marked as **included** — the auto-ingest scope for the **Included folders** picker (`/documents/included`). Checking a folder includes it recursively; **Sync now** (`POST /included-folders/sync`) walks these folders and fires the `documents.document.uploaded` pipeline event per file, so a consumer (cog-ingest) ingests them. Backs `GET/POST/DELETE /included-folders`.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `String` | `@id @default(cuid())` |
| `userId` | `String` | Owner |
| `providerId` | `String` | References `doc_storage_provider.id` |
| `folderPath` | `String` | Folder marked as included |
| `recursive` | `Boolean` | `@default(true)` — include descendant folders |
| `createdAt` | `DateTime` | `@default(now())` |

```prisma
model doc_included_folder {
  id         String   @id @default(cuid())
  userId     String
  providerId String
  folderPath String
  recursive  Boolean  @default(true)
  createdAt  DateTime @default(now())

  @@unique([userId, providerId, folderPath])
  @@index([userId])
  @@index([userId, providerId])
  @@map("doc_included_folders")
}
```

The `@@unique([userId, providerId, folderPath])` constraint means marking the same folder twice is idempotent. `addIncludedFolder` reuses the `resolveFileProvider` guard, so a user can only include folders they can actually reach.

## `doc_parsed_artefact`

Stores the **output an external parser produced** for a source file — for example the JSON the cog-ingest Docling sidecar extracts. This module **never parses content itself**; it only persists the byproduct so re-ingest, re-extraction, and re-chunking never re-parse. A row points at both the original **source** (`sourceProviderId` + `sourceRemotePath`, optionally a `doc_document.id`) and the stored **artefact** (`artefactProviderId` + `artefactPath`).

Artefacts default to a **derived writable area** (`DOC_ARTEFACT_PREFIX`, default `.derived-artefacts`) rather than beside the original — the original may sit on a read-only/evidence provider that rejects writes — and an explicit `target` can override that. Versioning keeps a monotonic `version` ordinal, but the **content hash is the dedup key**: identical source bytes reuse the existing artefact. On the shared app-default provider, artefact bytes are namespaced under the user's `u/<userId>/` prefix.

| Field | Type | Notes |
|-------|------|-------|
| `id` | `String` | `@id @default(cuid())` |
| `userId` | `String` | Owner |
| `sourceProviderId` | `String` | Provider of the original source file |
| `sourceRemotePath` | `String` | Path of the original source within its provider |
| `documentId` | `String?` | Optional `doc_document.id` when a durable reference exists |
| `sourceContentHash` | `String?` | SHA-256 of the source bytes — the dedup key |
| `format` | `String` | Artefact format, e.g. `docling-json`, `markdown` |
| `version` | `Int` | `@default(1)` — monotonic ordinal per `(source, format)` |
| `artefactProviderId` | `String` | Provider the artefact bytes are stored on |
| `artefactPath` | `String` | Path of the artefact within its provider |
| `artefactHash` | `String` | SHA-256 of the artefact bytes (integrity) |
| `sizeBytes` | `Int?` | Artefact size in bytes |
| `mimeType` | `String?` | Artefact MIME type |
| `producer` | `String?` | What produced it, e.g. `cog-ingest/docling` |
| `metadata` | `Json?` | Producer metadata |
| `createdAt` | `DateTime` | `@default(now())` |
| `updatedAt` | `DateTime` | `@updatedAt` |

```prisma
model doc_parsed_artefact {
  id                 String   @id @default(cuid())
  userId             String
  sourceProviderId   String
  sourceRemotePath   String
  documentId         String?
  sourceContentHash  String?
  format             String
  version            Int      @default(1)
  artefactProviderId String
  artefactPath       String
  artefactHash       String
  sizeBytes          Int?
  mimeType           String?
  producer           String?
  metadata           Json?
  createdAt          DateTime @default(now())
  updatedAt          DateTime @updatedAt

  @@unique([userId, sourceProviderId, sourceRemotePath, format, version])
  @@index([userId])
  @@index([documentId])
  @@index([userId, sourceProviderId, sourceRemotePath])
  @@index([sourceContentHash])
  @@map("doc_parsed_artefacts")
}
```

<Aside type="note" title="Byproduct, not content">
Storing parsed artefacts does not break the connector principle — the module still never authors or parses file content. It persists a derived byproduct that an external parser handed it, keyed to the source, so expensive parsing happens once. Producers write artefacts in-process via `serviceRegistry.get('document-management').putParsedArtefact(...)`; there is no HTTP `PUT`. See [Integration](/document-management/integration/#parsed-artefacts--provenance).
</Aside>

## `doc_pending_reconcile`

Records a file uploaded to a **Local Connect (ephemeral) default while the machine was offline**. The bytes are staged on the durable shared default; the `doc_document` reference points at the staged location so the file is immediately usable, and this row records the intent to organise the bytes **into the local folder** — and re-point the reference route — once the machine reconnects. No document is ever duplicated; only the route changes. Rows are cleared on account erasure (along with the staged bytes).

| Field | Type | Notes |
|-------|------|-------|
| `id` | `String` | `@id @default(cuid())` |
| `userId` | `String` | Owner |
| `documentId` | `String` | The `doc_document` reference being re-pointed |
| `targetProviderId` | `String` | The local/ephemeral provider the file belongs in |
| `targetRemotePath` | `String` | Intended path within the local provider |
| `stagingProviderId` | `String` | Durable provider currently holding the bytes |
| `stagingRemotePath` | `String` | Path of the staged bytes within `stagingProviderId` |
| `fileName` | `String` | |
| `mimeType` | `String?` | |
| `status` | `String` | `@default("pending")` — `pending` \| `reconciled` \| `failed` |
| `attempts` | `Int` | `@default(0)` — reconcile attempts |
| `lastError` | `String?` | Last reconcile failure detail |
| `createdAt` | `DateTime` | `@default(now())` |
| `reconciledAt` | `DateTime?` | When the file was organised into the local folder |

```prisma
model doc_pending_reconcile {
  id                String    @id @default(cuid())
  userId            String
  documentId        String
  targetProviderId  String
  targetRemotePath  String
  stagingProviderId String
  stagingRemotePath String
  fileName          String
  mimeType          String?
  status            String    @default("pending")
  attempts          Int       @default(0)
  lastError         String?
  createdAt         DateTime  @default(now())
  reconciledAt      DateTime?

  @@index([userId])
  @@index([userId, targetProviderId, status])
  @@index([documentId])
  @@map("doc_pending_reconciles")
}
```

<Aside type="note" title="The route is the source of truth">
Reconcile moves bytes and updates the reference's `providerId` + `remotePath`; it never duplicates a document. A consumer (e.g. cog-ingest) that holds the stable `documentId` reads the file wherever it currently lives — staging while offline, the local folder after reconnect — with no change on its side.
</Aside>

## Conventions

- **Self-contained.** No `@relation` directives; foreign keys are plain `String` fields with `@@index`. This lets the module install independently without modifying other modules' tables. See the [Module Database](/module-starter/database/) guide.
- **User-owned.** Every table carries `userId`; queries always filter by it and ownership is enforced in the service layer.
- **Plural table names.** Each model `@@map`s to a snake_case table — usually pluralised (`doc_storage_providers`, `doc_documents`, `doc_node_links`, `doc_folder_bookmarks`, `doc_included_folders`, `doc_parsed_artefacts`); the singleton `doc_app_settings` and the `doc_recent_access` log keep their singular names.
