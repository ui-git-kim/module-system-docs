<Aside type="caution" title="Removed in v2.1.7">
Working memory is not part of Cognitive Pipeline at the moment. Kim took it out on 2026-11-28, to be built again with the embedding and retrieval work.
</Aside>

## Why

- **Nothing used it.** No module called the working-memory service. The connections it was meant to build from retrieval were never made, because they were only made when a working-memory session ended, and nothing ended one.
- **AI Chat already has a layer of memory.** Cognitive Pipeline's job is to expand that, and that design belongs with retrieval.
- **One kind of it sat under another node.** A session's working memory was placed under the session's node, and Structure is removing that.

## What was removed

- The `working-memory` node type is no longer seeded, and the `workingMemory` service is gone from `serviceRegistry.get('cognitive-pipeline')`.
- The five `cognitive-pipeline.working-memory.*` actions and the two `cognitive-pipeline.working-memory.*` filters are gone.
- `retrieve()` no longer records which nodes were retrieved together, and its `sessionId` option is gone.
- Consolidation, the step that turned those records into `co-activated` connections, is gone. So is the "Working memory" line on the admin overview.

## What is left

- **The `cog_working_memory_events` table.** The engine still declares it, so the table stays. Nothing writes to it. Rows from earlier versions are cleared when the backend starts, except for a person whose records are on hold. The table is still covered by the personal-data export and by account erasure.
- **A "Working Memory" node type in Structure,** in an app that ran an earlier version. The module no longer uses it. Delete it in Structure's admin if you do not want it.
- **The engine** (cognitive-db) still ships its working-memory code. Nothing calls it.

The earlier design is described in the [changelog](/modules/cognitive-pipeline/changelog/) (v1.12.0 onwards) and in this page's history. What comes next is on the [roadmap](/modules/cognitive-pipeline/roadmap/).
