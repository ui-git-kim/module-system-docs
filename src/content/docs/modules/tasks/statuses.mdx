## Parked to Archived

A starting point for a stage template (Admin › Tasks › Stage templates › New template), in the owner's words:

| Stage | Meaning | On Today |
|---|---|---|
| **Parked** (new tasks start here) | Not started | Suggested once it has What it takes |
| **Active** | Doing | Suggested first |
| **Waiting** | Waiting | Not suggested; on the Waiting page |
| **Scheduled** | Scheduled | Not before its day; brought forward on it |
| **Completed** | Done | On the done list |
| **Delegated** | Done, handed to someone | Not suggested; Today brings up its follow-up day |
| **Archived** | No longer needed | Not shown; kept on record |

- **Parked** is "not started" without the weight of it (the owner: "without the feeling of" not having started yet): a parked task is just where it's sitting for now.
- **Done** moves a task to **Completed**, the first Done stage.
- **Delegated** is done: finished as far as you're concerned, because someone else has it (the owner: "since these are solo apps - its a done status"). It isn't on the Waiting list.

<Steps>

1. In Admin › Tasks › Stage templates, start a new template from **Parked to Archived** and save it.
2. **Apply it** to the types that should use it. Tasks asks what happens to entries on stages that go, as it always does, and asks you to confirm it's you (the starter's step-up, since v1.22.87): it moves everyone's entries and can't be undone.
3. Applying it notes **Delegated** on each type as its stage for handing a task to someone (Entry types, a type's **Edit** › Tasks › **Handed to someone**).

</Steps>

## Scheduled

A seventh meaning (v1.22.64): **it has its day**, its due date. Today doesn't suggest a scheduled task before that day, and on the day brings it forward, first among the suggestions. After its day it's suggested like any task that isn't started, with nothing said about the day that went. A scheduled task with no due date is suggested like any other.

Any template can use it: in the stage editor, **Scheduled** sits between Waiting and Done.

## Handed to someone

A type can have one Done stage that means "it's with someone else" (**Delegated**, in Parked to Archived). Moving a task there asks, once and quietly, **Who has it?**, with a day to **Follow up on**. Nothing has to be filled in. On that day Today brings it up: **Followed up** clears the day; **Later** puts it a week on. The task stays done throughout.

An admin chooses the stage on Entry types (a type's **Edit** › Tasks › **Handed to someone**), shown when a type has more than one Done stage. In the stage editor, a Done stage can be ticked **Handed to someone** (one per template), and applying the template notes it on the type.

## Waiting on

From the owner's waiting-on sheet. A task in a stage that means Waiting can say:

- **Waiting on**: who or what.
- **What for**: a few words.
- **Asked on**: a day.
- **Check back**: a day to check in about it.

Moving a task into a Waiting stage asks **Who or what is it waiting on?**, once; nothing has to be filled in. The same fields are in the task editor while it's waiting, and on its page in Structure: they are real Structure fields Tasks supplies (Waiting on, What for, Asked on, Check back), which an admin can lay out or switch off per type (Entry types › **Waiting on**; off, they stay on the type as its own, with their values).

### The Waiting page

**Waiting**, beside All tasks in Tasks' views (shown once a type has a stage that means Waiting): every waiting task with who, what for, when asked and when to check back, in check-back order (a task with no day comes last). **Heard back** moves one on to Not started (Parked); **Later** puts its day a week on; **Open** shows the task.

### Today's check-ins

On the day to check back (or after it), Today shows a quiet **To check in on** card above the suggestions, at most five, with the same **Heard back** (or **Followed up**) and **Later**. With nothing to check in on there's no card at all.

<Aside type="note" title="Calm rules">
No "follow up now", no red, no counts. A day to check back that has gone is just a day: Today says nothing about it being past.
</Aside>
