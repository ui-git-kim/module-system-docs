Since v1.22.63 a task can say more about itself, always in words, never as a score or a count. These are P2 of the [Task Parts Plan](/modules/tasks/task-parts-plan/), in the owner's own words. Each is a real Structure field Tasks supplies to every kind used for tasks, so it shows on the task's page in Structure too, where an admin can lay it out on the kind's Fields tab ("From Tasks").

In the task editor they sit under **What it takes**. Nothing has to be filled in.

---

## What it takes

How long a task takes, without counting minutes (the owner: "not in a how many mins type thing"). It replaces Size.

| Word | Roughly |
|---|---|
| **Blink** | Done before you know it |
| **Brief** | A few minutes |
| **In a sitting** | One go |
| **Multi-session** | A few goes |
| **Deep dive** | Real time and focus |

A task still needs one before Today suggests it. Every task keeps the size it had: Light reads as Brief, Medium as In a sitting and Big as Multi-session.

## Where it sits

How much a task matters and how much room it has. One measure (the owner: "that feels like it covers it all").

| Word | What it means |
|---|---|
| **Bound** | Tied to a time or a promise: it can't move |
| **Pivotal** | Important, essential: other things hang on it |
| **Routine** | Keeps things going |
| **Flexible** | Matters, and can happen whenever it suits |
| **Bonus** | Nice if it happens; nothing rides on it |

**Essential comes from it.** Where Where it sits is chosen, the words an admin picks count as essential on a survival day (**Bound** and **Pivotal** unless changed). Where it isn't chosen, the task's **Essential** switch still decides, so nothing changes for tasks marked essential before. The switch shows in the editor only for those, and for a kind without the measures.

"Must" and "priority" are never used: Where it sits says the same thing more kindly.

## How hard it feels

**Easy · A bit of a push · Hard to start · Really hard.** About you, today, not how big the task is: hanging out washing can be really hard while a complicated project is easy. It's kept apart from What it takes on purpose.

## Time sensitive, and When it suits

- **Time sensitive** (on or off): its date matters. Off, it can happen whenever suits.
- **When it suits** (while it isn't time sensitive): **Morning · Afternoon · Evening · Late at night · Any time**, any of them. Today leans towards a task at the times it suits: checking in at 8 in the morning brings a morning task forward, as a preferred one is. Any time leans no way. The times are the same as Today's rules' **Time of day**.

## Travel

**Travel** (on or off), with **Where** (a few words) and **Travel time**: **A short trip · About an hour · Half a day · All day**. Today doesn't count travel time yet; capacity may later.

## Who it's for

A link to an entry: a client, a child, you, or the court. Which kinds of entry it can link to is the admin's choice (Admin › Tasks › Suggest & capacity › Measures); until some are chosen, tasks have no Who it's for. It's set on the task's page in Structure.

---

## Today and the measures

- **The kinds of day** read What it takes: a survival day offers only essentials, quickest first; a steady day offers **Blink, Brief and In a sitting**; a full-energy day offers all five, **Deep dive** first.
- **Today's rules** can test every measure on **Each task** (What it takes, Where it sits, How hard it feels, Time sensitive, When it suits, Needs travel) and switch each of the five sizes on or off for **The day**. For example: when the feeling is tired, leave out tasks that are Really hard. See [Setting Up Today's Rules](/modules/tasks/today-rules/).

---

## Setting it up (an admin)

- **Admin › Tasks › Entry types**, a kind's **Edit** › Tasks › **Measures**: on unless switched off. Switched off, the fields stay on the kind as its own, with every value, the way they do when Tasks is switched off for a kind; What it takes, Essential and the dates are always there.
- **Admin › Tasks › Suggest & capacity › Measures**:
  - **Count as essential on a survival day**: the Where it sits words that do (Bound and Pivotal to start).
  - **Who it's for links to**: the kinds of entry Who it's for can link to (up to 10). None, no Who it's for field.
